# MultiTeam Project Rules & Standards

## Project Context
- **Name**: MultiTeam
- **Framework**: .NET 8.0 Windows (WPF)
- **Engine**: Microsoft.Web.WebView2 (Chromium Edge Runtime)
- **Purpose**: Lightweight Multi-Account Microsoft Teams client with isolated session storage.

## Enforced Invariants
- `R_CORE`: Clean single-responsibility separation between UI (`MainWindow`), Data Model (`TeamAccount`), and Persistence (`AccountStore`).
- `R_PROOF`: Zero-trust empirical proof (compiler exit code 0 required for all builds).
- `R_UI`: Anti-slop UI tokens (Tailwind Slate `#0f172a`, `#1e293b`, `#334155`, `#4f46e5`), crisp elevation, unread badges, no gratuitous gradients.
- `R_PUB`: Framework-dependent single-file publish (`-p:PublishSingleFile=true --self-contained false`).
